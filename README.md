# 🧠 Paraphrase-Robust Fake News Detection

This project focuses on building a robust fake news detection system that remains consistent across paraphrased inputs and adversarial text variations.

## 🚀 Motivation
Traditional fake news models fail when the same claim is rephrased.
This project aims to improve robustness using paraphrase-aware learning and evidence-based reasoning.

## 🧩 Features
- Fake news classification (Real vs Fake)
- Paraphrase robustness testing
- Evidence-based verification (FEVER-style)
- NLP preprocessing & feature engineering

## 📊 Datasets
- LIAR Dataset
- FakeNewsNet
- FEVER Dataset

## ⚙️ Tech Stack
- Python
- Scikit-learn
- TensorFlow / PyTorch
- NLP (NLTK, SpaCy)

## 🧪 Models
- Logistic Regression (baseline)
- Random Forest
- LSTM
- Transformer-based models (future work)

## 📈 Evaluation
- Accuracy
- Precision / Recall / F1-score
- Robustness against paraphrased inputs

## 🧠 Research Contribution
- Introduces paraphrase-aware training
- Improves model consistency across text variations
- Addresses LLM-generated misinformation challenges
